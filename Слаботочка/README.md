## Важно
- Пожарная сигнализация и СОУЭ (монтаж и ТО) — только с **лицензией МЧС**. Без неё берём видеонаблюдение, домофоны, СКУД, СКС/Wi‑Fi, либо работаем через лицензированную фирму.
- Не уводить клиентов основного работодателя, проверить трудовой договор.
- Доход от частных заказов оформлять через самозанятость («Мой налог», 4% с физлиц, 6% с юрлиц).
