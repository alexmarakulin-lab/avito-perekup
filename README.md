# Бот-перекуп — Краснодар

Telegram-бот под перепродажу б/у техники и инструмента: следит за новыми
лотами на Авито, копит историю цен и консультирует по сделке.

| Файл | Что это |
|---|---|
| `avito_bot.py` | точка входа: команды, кнопки, контроль доступа |
| `avito_monitor.py` | монитор Авито: запросы, разбор выдачи, база, статистика цен |
| `resale_expert.py` | консультант по сделкам через Groq, опирается на собранную статистику |
| `test_*.py` | оффлайн-проверки, сеть не нужна |

## Что умеет

**Ловит свежие лоты.** Четыре категории — инструмент, садовая техника,
кондиционеры, мебель и бытовая техника. Круг обхода 8–10 минут, присылает
только то, чего раньше не видел и что дешевле медианы рынка.

**Считает рынок.** Медиана по скользящему окну в 21 день плюс отслеживание
снятых объявлений — то есть реальные цены сделок, а не цены хотелок.

**Отвечает на вопросы по сделке.** «Перфоратор за 3500, брать?», «что смотреть
в б/у стиралке», «как сбить цену». Где по теме есть накопленная статистика,
она подставляется в ответ, так что цифры свои, а не средние по стране.

## Быстрый старт

На чистом сервере одной командой — скрипт поставит Docker, спросит токен
и запустит бота:

```bash
bash setup.sh
```

Вручную, если хочется контроля:

```bash
cp .env.example .env && nano .env     # вставь AVITO_BOT_TOKEN от @BotFather
docker compose up -d
```

Полный порядок первого запуска, настройки и разбор граблей — в [AVITO.md](AVITO.md).
