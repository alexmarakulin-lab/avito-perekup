# Айсгергер-style track builder

Сборка трека в стиле dark-trap (Айсгергер / IceGergert) из чистого вокала.
Всё синтезируется и сводится на `numpy`/`scipy`/`soundfile` — без внешних DAW/сэмплов.

## Файлы
- `analyze.py` — анализ вокала: тональность (Крумхансль), темп (автокорреляция onset-огибающей),
  карта голосовой активности.
- `build_track.py` — синтез инструментала (808, half-time барабаны, пэды, dark-bell лид)
  и обработка/сведение вокала (presence-EQ, компрессия, стерео-хорус, дилей в темпе, plate-реверб).

## Параметры трека
- Тональность: **F minor**
- Темп: **125 BPM** (half-time грув)
- Прогрессия: **Fm – Db – Ab – Eb** (i–VI–III–VII)

## Как запустить
```bash
pip install numpy scipy soundfile
# положить вокал рядом как vocal_src.wav (mono/stereo, 48 kHz)
python3 analyze.py        # опционально: посмотреть тональность/темп
python3 build_track.py    # -> final_mix.wav / final_mix.mp3
```

## Замечания
- Аудиофайлы (`*.wav`, `*.mp3`) намеренно в `.gitignore` — приватный вокал и рендеры
  в репозиторий не коммитятся.
- Настоящей пич-коррекции (автотюн) в цепочке нет — вокал обрабатывается эффектами
  пространства/ширины, но ноты в тональность не подтягиваются.
