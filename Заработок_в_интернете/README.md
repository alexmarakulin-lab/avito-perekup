## Правила контента (по нашей аналитике)
- Заходит: **читеры / «проверка на честность»**, админ и ловушки, разрушение с развязкой (цунами, украл дом), пранки Зени (взлом ПК).
- Не заходит: болтовня без действия, реакции без Домера/Зени в кадре, завязка без развязки, «откровенные» темы (режутся до ~14 просмотров), реклама Prime Oracles на этом канале (≈0).
- Длина 30–60 с, полная история «завязка → действие → развязка».
- Заголовок: «[Кто] [сделал дерзкое] [кому]» или интрига «Он уже праздновал победу…».
- Не больше 3 нарезок с одного видео Домера.
- **Выкладывать по 1 ролику в день в 19:00** через «Запланировать», не пачкой.

## Что не делаем
Казино, букмекеры (Winline), крипто‑биржи и токены, VPN — канал смотрят дети. Не обходим проверку документов (KYC) на Whop и подобных. Не платим за «доступ к заданиям».
