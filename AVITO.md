# Монитор Авито: перекуп по Краснодару

Следит за новыми объявлениями, копит историю цен и присылает в Telegram
только то, что дешевле рынка.

Это **отдельный бот** (`avito_bot.py`) на своём токене — со слаботочным
экспертом он никак не связан и падает/перезапускается независимо. Общий у
них только код монитора (`avito_monitor.py`) и Docker-образ.

## Что он делает

**Ловит свежие лоты.** Обходит категории по сортировке «сначала новые»,
запоминает всё увиденное в SQLite и шлёт уведомление только на то, чего
раньше не было. Полный круг — примерно 8–10 минут. Это и есть смысл затеи:
дешёвый лот живёт 10–20 минут, кто первый написал — тот и купил.

**Отличает находку от обычной цены.** Первые дни шлёт всё, что укладывается
в бюджет, — так набирается выборка. Как только по ключевому слову накопится
8 наблюдений, включается фильтр по медиане: тревожит только если цена ниже
медианы минимум на 20%, а пометку «🔥» ставит при −40% и ниже. Медиана
считается по скользящему окну в 21 день, то есть сама подстраивается под
сезон — для кондиционеров это принципиально.

**Отслеживает реальные продажи.** Раз в сутки перепроверяет ранее найденные
лоты: снятое с публикации помечается как проданное. Через пару недель это
даёт то, чего не видно в выдаче, — по какой цене вещь действительно уходит,
а не по какой висит месяцами.

**Присылает сводку в 21:00** — сколько новых лотов по каждой категории,
медиана, минимум и что ушло с рынка.

## Порядок запуска

**1. Завести бота.** В Telegram открой `@BotFather` → `/newbot` → имя (любое,
например «Авито Краснодар») → username, обязательно заканчивается на `bot`.
BotFather выдаст токен вида `7123456789:AAH...` — это и есть `AVITO_BOT_TOKEN`.

**2. Заполнить `.env`** (на сервере, см. раздел «Где запускать»):

```bash
cp .env.example .env
nano .env          # вставь AVITO_BOT_TOKEN
```

**3. Поднять:** `docker compose up -d avito`

**4. Закрыть от чужих.** Напиши боту `/myid`, полученное число впиши в
`AVITO_OWNER_ID` в `.env` и перезапусти: `docker compose up -d avito`.
Пока переменная пустая, боту ответит любой, кто наткнётся на него поиском, —
и будет гонять твой парсер под твоим же IP.

**5. Проверить связь** — кнопка «🔍 Проверить Авито». Покажет, сколько
карточек удалось прочитать. Ноль — зови меня, поправлю селекторы.

**6. Включить** — кнопка «🟢 Включить».

## Команды

Всё есть на кнопках, команды — для тех же действий с клавиатуры.

| Команда | Что делает |
|---|---|
| `/avito` | статус, размер базы, расчётное время круга |
| `/avito_on` | включить; чат, где введена команда, становится адресом уведомлений |
| `/avito_off` | выключить (база и история цен сохраняются) |
| `/avito_report` | сводка за сутки прямо сейчас |
| `/avito_test [запрос]` | живая диагностика: дошли ли до Авито и понимаем ли выдачу |
| `/myid` | свой Telegram ID для `AVITO_OWNER_ID` |

**`/avito_test` — первое, что нужно запустить после разворачивания.** Он
покажет, сколько карточек удалось распарсить. Если ноль — Авито либо сменил
вёрстку, либо блокирует IP, и это будет видно сразу, а не через неделю тишины.

## Категории и настройки

Категории и ключевые слова лежат в `CATEGORIES` в начале `avito_monitor.py` —
правятся руками, логику трогать не нужно. Сейчас настроено четыре: инструмент
и стройка, электро- и садовая техника, кондиционеры, мебель и бытовая техника.

Всё остальное — через переменные окружения:

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `AVITO_MAX_PRICE` | `5000` | потолок закупки на лот |
| `AVITO_MIN_PRICE` | `300` | ниже этого — мусор или развод |
| `AVITO_REGION` | `krasnodar` | регион в адресе Авито |
| `AVITO_DEAL_RATIO` | `0.6` | доля от медианы для пометки «🔥» |
| `AVITO_DIGEST_HOUR` | `21` | час суточного отчёта |
| `AVITO_REQ_DELAY_MIN/MAX` | `8` / `16` | пауза между запросами, секунды |
| `AVITO_CYCLE_PAUSE` | `120` | пауза между кругами, секунды |
| `AVITO_DB` | `avito.db` | путь к базе |
| `AVITO_PROXY` | — | прокси, если IP словил блокировку |
| `AVITO_BOT_TOKEN` | — | токен бота-перекупа, обязателен |
| `AVITO_OWNER_ID` | — | твой Telegram ID; пусто = бот открыт всем |

Паузы уменьшать не советую. 8–16 секунд между запросами — это режим, в котором
парсер живёт годами. На 2–3 секундах блокировка прилетает за первые сутки, и
дальше нужен прокси, то есть лишние деньги и лишняя точка отказа.

## Где запускать

Нужен **сервер с российским IP и круглосуточной работой**. С зарубежного адреса
Авито блокирует заметно быстрее, а с домашнего ноутбука пропускается всё, что
появляется ночью и ранним утром, — а это как раз лучшее время для лотов от
съезжающих и от тех, кто выкладывает «срочно, уезжаю».

Подойдёт любой дешёвый российский VPS начального уровня — Timeweb Cloud, Beget,
VDSina, RuVDS. Ресурсов нужно немного: 1 vCPU и 1 ГБ памяти хватает с запасом,
это самый нижний тариф, порядка нескольких сотен рублей в месяц. Бери Ubuntu
22.04 или 24.04 и ставь через Docker.

```bash
apt update && apt install -y docker.io docker-compose-plugin git
git clone <репозиторий> && cd slabotochny-bot
cp .env.example .env && nano .env      # вставь AVITO_BOT_TOKEN
docker compose up -d avito
docker compose logs -f avito           # посмотреть, что поднялось
```

Старый бот по слаботочке поднимается отдельно: `docker compose up -d expert`.
Не нужен — просто не запускай, сервисы независимы.

База лежит в `./data` рядом с проектом (том прописан в `docker-compose.yml`).
Каталог трогать нельзя: в нём вся накопленная статистика цен, ради которой
всё и затевалось. Удалишь — начнёшь копить заново с нуля.

Проверить, что логика цела, можно без сети и без Авито:

```bash
python3 test_avito_monitor.py    # 44 проверки логики монитора
python3 test_avito_bot.py        # 21 проверка обвязки бота
```

Разбор JSON и разметки, дедупликация, расчёт медианы, отсечение мусора,
распознавание блокировок, контроль доступа, маршрутизация кнопок.

## Чего он не умеет

Парсер написан по известной структуре выдачи Авито, но **на живой выдаче не
проверялся** — из среды, где он собирался, авито.ру недоступен. Поэтому в нём
две независимые стратегии разбора (встроенный JSON и разметка по `data-marker`)
и команда `/avito_test`. Если после развёртывания тест покажет ноль карточек —
пришли мне вывод, поправлю селекторы под текущую вёрстку.

Автоматически он ничего не покупает и не пишет продавцам — только находит и
показывает. Первое сообщение продавцу пишешь сам, и это правильно: по тому,
как человек отвечает, сразу видно, торопится он или будет мурыжить неделю.

## Практика

Правило, которое экономит больше всего денег: **закупка не дороже 30–35% от
цены продажи**. Всё, что выше, съедается бензином, временем на встречи и
торгом. Бот подсказывает медиану — от неё и считай.

Второе: продавать выгоднее покомпонентно, а не комплектом. Комплект — это одна
цена и один покупатель, разбор — пять объявлений и в полтора-два раза больше
суммарно.
